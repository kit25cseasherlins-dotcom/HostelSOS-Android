# 🏠 HostelSOS - Android App

HostelSOS is an anonymous hostel issue reporting application designed to help students report hostel-related problems without revealing their identity. The application provides a safe and secure platform for students to communicate issues directly to hostel management.

---

## 📱 Features

- 🔒 100% Anonymous issue reporting
- 📝 Simple and user-friendly interface
- 📊 Admin dashboard for issue management
- ⚡ Real-time updates
- ☁️ Cloud database integration with Supabase
- 📱 Android application with responsive design

---

## 🎯 Problem Statement

Many students living in hostels hesitate to report issues such as poor food quality, water shortages, electricity failures, Wi-Fi problems, cleanliness concerns, or safety issues due to fear of being identified.

HostelSOS enables students to report these issues anonymously, encouraging open communication while helping hostel management resolve problems efficiently.


2. Open the project in Android Studio.

3. Sync Gradle.

4. Run the application on an Android emulator or physical device.
